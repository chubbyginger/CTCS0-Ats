# CTCS0-Ats
CTCS-0列控系统插件，适用于BVE Trainsim 5/6

## Section配置

| Index | 机车信号码 | 信号含义 |
| ----- | --- | --------- |
| 0 | HU | 红灯 |
| 2 | U | 黄灯 |
| 3 | LU | 绿黄灯 |
| 4 | L | 绿灯 |
| 5 | L2 | |
| 6 | L3 | |
| 7 | L4 | |
| 8 | L5 | |
| 不使用 | H | 绝对停止信号 |
| 9 | HB | 引导信号或容许信号 |
| 10 | UU | 双黄灯 |
| 11 | UUS | 黄闪黄 |
| 12 | U2 | 前方为双黄灯 |
| 13 | U2S | 前方为黄闪黄 |
| 其他 | B | 无码 |

## Beacon配置
| Type | Section | Optional | 注释 |
| ---- | ------- | -------- | --- |
| 10 | 1 | 无 | 机车信号更新, 设置于闭塞分区入口处 |
| 11 | 任意 | 1：开始，2：结束 | 标注双黄灯发码区段，该区段内接收到任何进行信号均译码为UU |

## 配置说明

* 闭塞分区的入口处设置Beacon 10。
* 为了对出站的侧向进路进行防护，一般出站信号机显示绿灯/绿黄灯/黄灯时，轨道电路发UU码。由于BVE的设计原因，不可以直接用Section.Begin实现出站的UU发码，否则无法识别信号升级的情况。因此，Section.Begin仍然按照自动闭塞追踪逻辑配置，例如0、1、2、3，需要在侧线股道直到咽喉区结束的地段用Beacon 11标注双黄灯发码区段。
* 进路未开通的区段不需要发H码。当SetSignal读取到Section Index 0时，即为冒进信号，机车信号自动转为H码。
